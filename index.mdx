Ankara Chain is open-source infrastructure for tokenizing real-world assets (RWAs) in African markets. Think of it as the Stripe for asset tokenization — install the SDK, deploy pre-audited contracts to your chosen network, and keep full control of your business logic and on-chain keys.

## Get Started in Three Steps

<Steps>
  <Step title="Install the SDK or CLI">
    ```bash
    npm install @ankarachain/sdk
    # or use the CLI without installing:
    npx ankara init my-project
    ```
  </Step>
  <Step title="Deploy the Token Factory">
    Deploy the on-chain factory contract once per network. This is the entry point for all token deployments.
    ```bash
    npx ankara deploy-factory
    ```
  </Step>
  <Step title="Issue Your First Token">
    Pick an asset template and deploy a token in one command.
    ```bash
    npx ankara deploy
    ```
  </Step>
</Steps>
