The `@ankarachain/sdk` ships a `NETWORKS` map and a `getNetwork()` helper that give you the full configuration for every supported chain — chain ID, public RPC URL, block explorer link, and native currency details — without any runtime fetching. You can use them directly when building custom integrations or to validate that a given network identifier is supported before constructing a config.

```typescript
import { getNetwork, NETWORKS } from "@ankarachain/sdk";
```

---

## `getNetwork()`

Returns the `NetworkConfig` object for a given network key. Throws an `Error` if the key is not in the `NETWORKS` map.

```typescript
// Overloaded signatures (all return the same NETWORKS entry):
function getNetwork(network: EVMSupportedNetwork): EVMNetworkConfig;
function getNetwork(network: StellarSupportedNetwork): StellarNetworkConfig;
function getNetwork(network: SupportedNetwork): NetworkConfig;
```

**Example:**

```typescript
import { getNetwork } from "@ankarachain/sdk";

const poly = getNetwork("polygon");
console.log(poly.chainId);     // 137
console.log(poly.rpcUrl);      // "https://polygon-rpc.com"
console.log(poly.explorerUrl); // "https://polygonscan.com"

const stellar = getNetwork("stellar-testnet");
console.log(stellar.networkPassphrase); // "Test SDF Network ; September 2015"
console.log(stellar.rpcUrl);            // "https://soroban-testnet.stellar.org"
```

</Note>

## Overriding the RPC URL

You can pass a custom `rpcUrl` in your config to point the SDK at a private or premium RPC node — Alchemy, Infura, QuickNode, etc. The SDK will use your URL instead of the public default.

```typescript
import { TokenFactory } from "@ankarachain/sdk";
import { Wallet } from "ethers";

const factory = new TokenFactory({
  network: "polygon",
  signer: new Wallet(process.env.PRIVATE_KEY!),
  rpcUrl: "https://polygon-mainnet.g.alchemy.com/v2/YOUR_API_KEY",
});
```

This is strongly recommended in production. Public RPC endpoints are rate-limited and unsuitable for high-volume use.

## `EVMNetworkConfig` and `StellarNetworkConfig` shapes

Both shapes share `name`, `rpcUrl`, `explorerUrl`, and `nativeCurrency`, but differ in their chain-identifying fields:

```typescript
export interface EVMNetworkConfig {
  chainFamily: "evm";
  chainId: number;
  name: string;
  rpcUrl: string;
  explorerUrl: string;
  nativeCurrency: { name: string; symbol: string; decimals: number };
}

export interface StellarNetworkConfig {
  chainFamily: "stellar";
  networkPassphrase: string;  // identifies which Stellar network a transaction targets
  name: string;
  rpcUrl: string;             // Soroban RPC endpoint — not a Horizon URL
  explorerUrl: string;
  nativeCurrency: { name: string; symbol: string; decimals: number };
}
```

Discriminate between them using the `chainFamily` field:

```typescript
import { getNetwork } from "@ankarachain/sdk";

const config = getNetwork("stellar-testnet");

if (config.chainFamily === "stellar") {
  console.log(config.networkPassphrase);
} else {
  console.log(config.chainId);
}
```
